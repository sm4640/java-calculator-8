# java-calculator-precourse

## 기능 목록
- 사용자 행위 안내, 입출력 처리
- 커스텀 구분자 시작,끝 판단 패턴 생성
- 커스텀 구분자 문자열 탐색
- split에 사용할 정규식으로 변환
- 0~9까지인지 체크
- Integer로 변환
- 분리한 숫자 계산
- 구분자들로 split 및 전체 흐름 통합

## 테스트 코드 상황 상정
- 커스텀 구분자 사용 (//;\n1 → 결과 : 1)
- 음수 입력 시 예외 발생 (-1,2,3 → IllegalArgumentException)
- 커스텀 구분자로 여러 숫자 합산 (//;\n10;20 → 결과 : 30)
- 기본 구분자 쉼표와 콜론 사용 (1,2:3 → 결과 : 6)
- 입력이 비어있는 경우 (\n → 결과 : 0)
- 숫자 아닌 문자 포함 시 예외 (1,a,3 → IllegalArgumentException)
- 기본+커스텀 구분자 혼용 (//|\n10,20:30|40 → 결과 : 100)
- 커스텀 구분자 선언 후 데이터 없음 (//|\n → 결과 : 0)
- 구분자만 있는 경우 (, -> 결과 : 0)

## 중점적으로 고려한 점
- OCP를 생각하여 커스텀 구분자 시작, 끝 패턴을 재설정하거나 기본 구분자 설정도 가능하도록 함
- SRP를 생각하여 한 함수에 하나의 기능만 담기 위해 노력함

## 파일 구조
- CalculatorController: 사용자 입력 → 서비스 호출 → 결과 출력
- CalculatorService: 문자열 분리, 숫자 변환, 합계 계산 등 핵심 로직 관리
- DelimiterParser: 커스텀 구분자 파싱 및 정규식 생성 전담
- StringUtils: 숫자 검증, 변환 등 범용 문자열 유틸
